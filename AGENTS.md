# Working on the Norwegian Plurality

This repository is a Norwegian Bokmål fork of *Plurality: The Future of Collaborative
Technology and Democracy*. The job is to carry all 35 chapters of the English book through
two stages into Norwegian.

This file is the single source of truth for both people and AI assistants. Tool-specific
files (`CLAUDE.md`, `.cursor/rules/`, `.continue/rules/`, `.github/copilot-instructions.md`)
are one-line pointers here — never copies. Edit this file; the pointers follow automatically.

## The pipeline

    contents/english/            the upstream book, read-only in this fork
      ↓  stage 1: simplify
    contents/simplified-english/ shorter, plainer English, same substance
      ↓  stage 2: translate
    contents/norwegian/          Norwegian Bokmål

**All three layers use the exact same filenames.** `3-2-connected-society.md` is the same
chapter in each folder. Norwegian titles live in the chapter's `#` heading and in
`translation/chapter-titles.tsv`, never in the filename.

## One chapter, one stage, one branch, one pull request

The book is worked in parallel. Every job is a single chapter at a single stage:

    simplify/3-2     edits only  contents/simplified-english/3-2-connected-society.md
    translate/3-2    edits only  contents/norwegian/3-2-connected-society.md

To see everything that can be started right now:

```bash
vp run translation:next
```

Every simplify job depends only on `contents/english/`, so all of them can run at once.
Each translate job depends on its own simplify output and on nothing else. There are no
chapter-to-chapter dependencies, because the two decisions that would create them —
Norwegian chapter titles and settled terminology — are already resolved up front.

### Files a chapter branch may change

- its one output file under `contents/simplified-english/` or `contents/norwegian/`
- `translation/proposals/<chapter-id>.tsv`, to propose terms the glossary lacks

### Files a chapter branch must not change

- `contents/english/` — upstream text; fixes go to the upstream repository
- `translation/glossary.tsv` and `translation/chapter-titles.tsv` — shared decisions. A
  maintainer folds proposals in between waves. Editing them from a chapter branch
  conflicts with every other branch in flight.
- `translation/progress.tsv` — generated by `vp run translation:progress`, not written by hand

## Hard rules — these are checked, and a pull request fails without them

Run the checker before opening a pull request:

```bash
vp run translation:validate
```

- **Every footnote marker in the source appears in the output.** `[^Deming]` in the English
  must survive into the simplified English and into the Norwegian. Footnote *definitions*
  stay in their original language — they are bibliography, not prose. Dropping citations is
  the single most common defect in this repo and it is invisible until typesetting.
- **Every figure reference survives.** Keep `figs/…` image paths and their `alt` text; the
  alt text gets translated, the path does not.
- **Cross-chapter links resolve.** Links to `https://www.plurality.net/v/chapters/<id>/…`
  must point at a chapter id that exists in `translation/chapter-titles.tsv`.
- **Cross-chapter link text matches the registry.** Where the English links using a
  chapter's actual title, the Norwegian must use that chapter's registered Norwegian title —
  even if that chapter has not been translated yet. Where the English links with prose
  ("a later chapter"), translate the prose freely.
- **Filenames match `contents/english/` exactly.**

## Judgment — not checked, reviewed by a human

### Stage 1, simplify

Work paragraph by paragraph. Keep the paragraph structure: one source paragraph becomes one
output paragraph, so the stages stay alignable.

- Break long sentences into shorter ones.
- Cut hedging and academic filler.
- Keep every argument, example, name and number. Simplifying is not summarising — if the
  output is much shorter than the input, content was lost rather than tightened. Expect
  roughly 55–95% of the source length.

### Stage 2, translate

- Natural Bokmål. Not stiff, not bureaucratic, not machine-literal.
- Consult `translation/glossary.tsv` for terminology. If a term is missing, propose it in
  `translation/proposals/<chapter-id>.tsv` rather than deciding silently.
- `policy` in the glossary means: `translate` use the Norwegian; `keep` leave the English
  as-is; `gloss` keep the English and add the Norwegian in parentheses at first use in the
  chapter.
- `⿻` is always the symbol, never spelled out.
- English survives on purpose inside quotations, work titles and proper names. *The Age of
  Surveillance Capitalism* stays in English.
- Expect roughly 70–115% of the simplified English length.

## Working without repository access

Contributors using a chat-only assistant can copy a ready-made prompt from
`docs/translation/prompts/`, paste it together with the chapter text and the relevant slice
of the glossary, and paste the result back into the correct file. The checker enforces the
same rules either way.

## Branches

`main` mirrors `upstream/main` exactly and never takes a fork commit. `norwegian` is the
default branch and where all work lands. Per-chapter branches start from `norwegian` and
merge back into it — including stage 1 work, which does *not* go to the `simplify` branch.
